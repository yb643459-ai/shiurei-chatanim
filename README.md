# 🔒 שיעורי חתנים (2.1)

> **שם קודם: SecureCopy.** השם הפנימי (תיקיית הנתונים, קובץ התוכנה, המתקין) נשאר SecureCopy בכוונה. פרטים ב-HANDOFF.md, והוראות להמשך העבודה ב-`איך-ממשיכים.md`.

אפליקציית Desktop (Electron, Windows) שמאפשרת לתלמיד להקליד קוד, לראות רק את התיקייה שהוקצתה לו, ולהעתיק ממנה קבצים **לדיסק נשלף בלבד**.
הממשק בנוי ב-**Material Design 3** (Material Web של גוגל), עם עברית/RTL, מצב בהיר וכהה.

## מה השתנה מגרסה 1

| נושא | גרסה 1 | גרסה 2 |
|---|---|---|
| קוד חד-פעמי | הוצג בלבד, לא נאכף | נאכף: קוד נצרך בהעתקה המוצלחת הראשונה (אפשר לקבוע 1 / כמה / ללא הגבלה) |
| הגנת תיקייה | הממשק קבע אילו נתיבים מותרים | התהליך הראשי בודק כל נתיב מול תיקיות הקוד (כולל `..` וקישורים סימבוליים) |
| יעד ההעתקה | נתיב שמגיע מהממשק | רק דיסק שזוהה כנשלף ברגע ההעתקה, ולא כונן המערכת |
| איחסון קודים | טקסט גלוי ב-JSON | גיבוב SHA-256 + salt. אי אפשר לראות קוד אחרי ההנפקה (רק 4 ספרות אחרונות) |
| סיסמת ניהול | `999999` ברירת מחדל | אין ברירת מחדל. מגדירים בהפעלה ראשונה. נשמרת ב-scrypt |
| ניחוש קודים | ללא הגבלה | נעילה מדורגת (30 שנ' ואילך) שנשמרת גם אחרי הפעלה מחדש |
| יצירת קודים | `Math.random` | `crypto.randomInt`, בלי כפילויות |
| PDF | פונטים לועזיים, עברית שבורה | נוצר דרך Chromium עם Heebo – עברית ו-RTL תקינים. הקודים נשמרים רק אם ה-PDF נכתב בהצלחה |
| זיהוי דיסקים | `wmic`/`Get-WmiObject` (לא קיימים בחלק מ-Windows 11) | `Get-CimInstance`, כולל כונני USB שמדווחים כקבועים |
| העתקה | דורסת קבצים | לא דורסת (`שם (1).pdf`), מנקה העתקה חלקית, סרגל התקדמות |
| ניתוק אוטומטי | אין | תלמיד ומנהל מנותקים אחרי חוסר פעילות (ניתן להגדרה) |
| יומן פעילות | אין | כניסות, העתקות, הנפקות וניסיונות כושלים (ללא הקודים עצמם) |
| XSS בשמות קבצים | `innerHTML` | אין `innerHTML`; CSP קשיח; sandbox |

## התקנה והרצה

דרישות: Node.js 18+ (מומלץ 22) ו-Windows.

```bash
npm install
npm start          # בונה את הממשק ומריץ
npm test           # בדיקות יחידה (37)
npm run test:e2e   # בדיקת הרצה מלאה של האפליקציה (חלון אמיתי, דיסק נשלף מדומה)
npm run diagnose:mtp  # אבחון טלפון מחובר (Windows)
npm run test:mtp-copy # העתקת קובץ בדיקה קטן לטלפון
npm run dist       # בניית מתקין NSIS ל-Windows בתיקיית dist/
```

> הערה: `npm run dist` רץ על Windows בלבד. המתקין נוצר בתיקייה `dist` בשם `SecureCopy-Setup-<גרסה>.exe`. הוא לא חתום דיגיטלית, ולכן Windows יציג אזהרה בהפעלה הראשונה.

## שימוש

1. **הפעלה ראשונה:** בוחרים סיסמת ניהול.
2. **הנפקת קודים:** לוחצים על 🛡 בפינה → סיסמה → לשונית "הנפקה". בוחרים תיקייה/ות, תווית, כמות, מספר שימושים ותוקף. נשמר PDF להדפסה. **שמור אותו, הקודים לא יוצגו שוב.**
3. **תלמיד:** מקליד קוד (גם במקלדת), מחבר דיסק נשלף, בוחר אותו ומעתיק קובץ או תיקייה.
4. **ניהול:** חיפוש, עריכת תיקיות/תוקף/שימושים, איפוס שימוש, מחיקה, יומן והגדרות.

## טלפון אנדרואיד (MTP)

טלפון שמחובר במצב **"העברת קבצים"** אין לו אות כונן, ולכן הוא מטופל בנפרד דרך מנגנון ה-Shell של Windows (כמו סייר הקבצים) ומופיע ברשימת היעדים כ-"שם הטלפון (טלפון)".
- הטלפון צריך להיות **פתוח (לא נעול)**, ובהתראה שבו צריך לבחור "העברת קבצים". אחרת הוא יופיע כנעול ולא ניתן לבחירה.
- הקבצים נכנסים לתיקיית `Download` בטלפון אם קיימת, אחרת לשורש האחסון.
- ההעתקה לטלפון איטית יותר, ו-Windows מציג חלון העתקה משלו. אל תסגור אותו. אין סרגל התקדמות מדויק.
- בזמן ההעתקה לטלפון יש כפתור **ביטול**. אם ההעתקה נתקעה, אפשר לבטל ולנסות שוב.
- אם הטלפון לא מופיע, הרץ `npm run diagnose:mtp` ושלח את הפלט.
- לבדיקת העתקה קטנה בלי הממשק: `npm run test:mtp-copy` (עם `-- --nopump` להשוואה).
- **תמיכת ה-MTP נבדקה רק מול סימולציה של Windows Shell (לא מול טלפון אמיתי).**

## מיגרציה מגרסה 1

בהפעלה הראשונה על מחשב שיש בו נתונים ישנים (`data.json` מגרסה 1) הם מומרים אוטומטית; נוצר גיבוי `data.v1.backup.json`.
קודים שכבר חולקו ממשיכים לעבוד **ללא הגבלת שימוש** (כדי לא לשבור אותם). סיסמת הניהול הישנה נשמרת, אלא אם היתה `999999` – אז תתבקש להגדיר חדשה.
הנתונים נמצאים ב-`%APPDATA%\SecureCopy\`.

## מגבלות

- זו הגנה מפני שימוש לא מורשה **בתוך התוכנה**. מי שיש לו גישת מנהל למחשב או גישה ישירה לתיקיית המקור, התוכנה לא תעצור אותו.
- ההגנה על "דיסק נשלף בלבד" תלויה בזיהוי של Windows. דיסק קשיח חיצוני שמוגדר כקבוע ושאינו USB לא יוצג. טלפונים (MTP) מוצגים רק ב-Windows.
- אם מאבדים את סיסמת הניהול אין שחזור (אפשר למחוק את `data.json`, אך אז כל הקודים אובדים).
